# 铁幕前线 · Iron Front

原创网页即时战略单人原型。Canvas 2D 绘制，无外部运行依赖、素材下载或账号要求。

## 运行

需要 Node.js 22 或更新版本。在仓库目录执行：

```sh
npm run dev
```

服务默认监听端口 3000；使用 `PORT=3001 npm run dev` 可切换端口。用浏览器访问服务器即可游戏。验证：`npm test`。

执行 `npm run build:demo` 会生成 `dist/iron-front-demo.html`，下载后可直接用桌面浏览器打开，无需服务器。修改游戏后需重新生成，已下载的旧文件不会自动更新。

## 玩法

- 开局选择阵营、国家、敌方国家和难度。侧栏「更换国家」打开设置；「返回当前战局」或 Esc 继续当前游戏，「部署部队」开始新的一局。
- 左键选择、拖动框选、Shift 追加选择、双击选择同类单位；Ctrl/Cmd+A 选择所有战斗部队。
- 右键移动；右键敌军发出攻击指令。按 A 或点击「进攻移动」，再左键地面，部队会在推进时自动攻击。
- 按 S 停止。按住鼠标中键拖动视野；方向键、W/D/I/J/K/L 或鼠标靠近战场边缘也可移动视野；小地图点击定位；H 返回基地。
- 空格暂停；Esc 取消部署与选择。
- 点击建筑卡片再点击战场部署，右键取消。建筑需在指挥中心 470 距离内，不能覆盖建筑、岩石与矿区。
- 初始拥有矿车、精炼厂、电站、兵营和少量部队。矿车自动采矿回款；新建精炼厂附送一辆矿车。
- 建造战车工厂后可以生产坦克和矿车。每个生产建筑各有一个队列，建筑施工共用队列。
- 战车工厂解锁航空基地与科技中心；航空基地生产本阵营飞行单位，科技中心解锁高级阵营单位。选中生产建筑后右键地面设置集结点，新部队会自动向集结点进攻移动。
- 电力不足时生产速度下降至 40%，防御炮塔停火。标准难度首次在 65 秒后进攻，此后每 48 秒增援；轻松为 90/60 秒，挑战为 50/36 秒。敌方根据所选国家派出混合部队，第二波加入特色地面单位，第四波开始可能加入空军。
- 部队提供视野，敌军在视野外隐藏。摧毁敌方指挥中心获胜，我方指挥中心被毁则失败。

## 阵营与国家

国家在本作中对应原创阵营与游戏加成。每个阵营有 8 种通用单位和 3 种特色单位，总共 17 种单位。

| 阵营 | 阵营特性 | 国家与加成 | 特色单位 |
| --- | --- | --- | --- |
| 联邦同盟 | 全军视野 +15% | 美国：空军火力 +20%；德国：装甲生命 +18% | 游骑狙击手、棱光战车、苍鹰武装直升机 |
| 钢铁联盟 | 装甲生命 +12% | 俄罗斯：装甲火力 +15%；中国：单位生产时间 −18% | 堡垒重型坦克、雷霆电磁战车、破城自行火炮 |
| 天穹议会 | 建筑耗电 −20% | 日本：特色机甲、卫士、无人机速度 +20%；韩国：作战单位射程 +12% | 护盾卫士、星陨战斗机甲、蜂群攻击无人机 |

通用单位为步枪兵、火箭兵、医疗兵、工程师、主战坦克、侦察战车、防空战车、采矿车。国家和阵营加成叠加；中国只加速单位生产，不加速建筑施工。装甲包括地面载具与机甲。

## 兵种搭配与支援

- 火箭兵能对空且对装甲伤害更高；防空车擅长击落飞机，地面火力较弱。普通坦克和炮塔无法攻击飞行单位。
- 狙击手克制步兵，侦察车拥有更大的视野。直升机、无人机越过地形；无人机可攻击空中单位，直升机负责对地攻击。
- 破城火炮射程远并有范围伤害，敌人太近时会后退。电磁战车和武装直升机也有范围打击。
- 医疗兵自动治疗附近步兵；右键友军步兵可跟随治疗。工程师自动维修附近建筑，右键己方建筑可维修；右键敌方非指挥中心建筑，在接近后占领，消耗一名工程师。指挥中心不可占领。
- 护盾卫士与机甲先用护盾吸收伤害；5 秒未受伤后，每秒恢复 18 护盾，生命不会随之恢复。
- 侧栏支援技能：联邦「战地维修」花费 400，修复点击位置 170 范围内装甲与建筑最多 350 生命，冷却 60 秒；钢铁「火力压制」花费 600，对 135 范围敌方地面单位造成 300 伤害，冷却 75 秒；天穹「应急能源」花费 350，提供 30 秒额外 150 电力并恢复全军护盾，冷却 70 秒。
- 区域支援必须点击当前视野内地面；右键或 Esc 取消瞄准。支援技能不会误伤友军。

## 当前范围

包含三阵营六国家、17 种单位、基地建设、基础科技解锁、资源经济、电力、生产与集结点、治疗维修与占领、护盾、空军和反制、阵营支援、A* 寻路、自动战斗、战争迷雾、小地图、不同难度的敌方波次和胜负结算。原型面向桌面鼠标键盘；没有联网对战、存档、音效或手机触控指令。地形树木属于装饰，建筑与岩石是地面寻路障碍。

`engine.js` 是独立模拟引擎，`game.js` 负责输入和绘制，`server.js` 提供本地静态服务。没有使用红警的名称、图像、声音或其他游戏素材。

## 开发验证

`npm test` 执行 23 项模拟测试。可选的完整浏览器回归会测试六国选择、科技建设、各阵营的全部可用单位生产、支援、迷雾、暂停和视野操作。测试使用额外资金和推进模拟时间作为测试夹具，生成的试玩文件没有这些入口。

在本云环境现有 Chromium 下运行浏览器回归：

```sh
npm install --prefix /tmp/rts-browser-tests --no-audit --no-fund playwright-core
npm run build:demo
PLAYWRIGHT_MODULE=/tmp/rts-browser-tests/node_modules/playwright-core/index.mjs node tests/browser-smoke.mjs
```

可用 `BROWSER_PATH` 指定 Chromium 可执行文件。截图输出在忽略的 `dist/browser-artifacts/` 中。云端浏览器限制直接导航到文件地址时，测试会加载单文件 HTML 内容进行验证；最终文件可下载至桌面浏览器试玩。
